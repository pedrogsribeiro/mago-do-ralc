### Hacktivista Desperto (Tradições / Adeptos da Virtualidade)
* **Atributos Sugeridos:** Força 2, Destreza 3, Vigor 3, Carisma 3, Manipulação 3, Aparência 2, Percepção 3, Inteligência 4, Raciocínio 4.
* **Habilidades Sugeridas:** Armas de Fogo 1, Briga 2, Ciência 2, Computação 5, Consciência 2, Direção 2, Enigmas 2, Erudição 3, Esportes 2, Furtividade 2, Investigação 4, Lábia 4, Manha 2, Mídia 3, Ocultismo 1, Pesquisa 3, Política 4, Prontidão 2, Tecnologia 4.
* **Arete:** 3 ou 4.
* **Esferas Sugeridas:** Correspondência / Dados 3, Forças 2, Mente 2, Entropia ou Tempo 2.
* **Força de Vontade:** 7.
* **Níveis de Vitalidade:** OK, -1, -1, -2, -2, -5, Incapacitado.
* **Absorção de Armadura:** 1 (Camiseta de fibra blindada; 4 dados de absorção total com Vigor).
* **Equipamento:** Smartphone ou tablet trinário aprimorado, pistola leve de defesa, passes de imprensa falsos, pendrives criptografados, motocicleta leve.
* **Paradigmas/Focos:** *Tudo são Dados* ou *A Tecnologia é a Resposta para Tudo*. Utiliza Hacking de Realidade, Hipertecnologia e Cibernética para alterar a física social.
