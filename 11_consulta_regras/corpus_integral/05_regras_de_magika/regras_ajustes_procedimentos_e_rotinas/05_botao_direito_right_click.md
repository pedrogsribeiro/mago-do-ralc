### Botão Direito (Right Click)
* **Esferas Exigidas:** Mente 3 / Conhecimento de Dados 3 (com Esferas opcionais: Forças 1, Vida 1, Matéria 1, Primórdio 1, Ciência Dimensional 2).
* **Mecânica:** Exibe uma interface de realidade aumentada direto no campo visual do mago (via implante ou óculos IVAE) focando em um alvo.
* **Sistema:** O mago acessa bancos de dados de rede locais para obter informações. O nível de detalhes depende dos sucessos no teste de Arete:
  * **1 Sucesso:** Dados Superficiais (Nome, dados vitais).
  * **2 Sucessos:** Dados Simples (Posts em redes sociais, projetos comuns).
  * **3 Sucessos:** Dados Incomuns (Registros telefônicos, plantas antigas).
  * **4 Sucessos:** Dados Protegidos (Ficha criminal, informações de votação).
  * **5 Sucessos:** Dados Secretos (Arquivos médicos e confidenciais).
  * *Modificadores:* Cada modo extra de varredura visual ativado simultaneamente (infravermelho de Forças 1, assinaturas vitais de Vida 1, etc.) soma **+1 de dificuldade** ao teste de Percepção do mago devido ao excesso de dados sobrepostos.
